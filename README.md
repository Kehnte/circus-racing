# 🏁 Circus Racing

**Circus Racing** is a real-time race management and streaming overlay tool built for **Star Citizen** events. Manage pilots, teams and ships from a control dashboard, then broadcast live standings and event alerts directly into **OBS** as browser sources — no capture card, no fuss.

---

## Features

- **Dashboard** — full race control panel to manage pilots, teams, ships, race settings, and trigger race events
- **Live leaderboard overlay** — displays lap counts, pilot standings, team colors, chrono times and race status (running, paused, restarted, finished)
- **Race alert overlay** — animated pop-up banners for fastest laps, incidents and finishes
- **Real-time sync** — all views stay in sync via Socket.IO; no page refresh needed
- **Session modes** — supports both lap-based and timed sessions with a live countdown
- **Weather & start type** — configurable race metadata displayed on the leaderboard
- **Import / Export** — save and restore the full race database as a JSON file

---

## Usage

1. Open the **Dashboard** to set up your race: add pilots, teams, ships and configure race settings.
2. Capture the **Leaderboard** and **Race Alert** overlays in OBS/streaming software as browser sources.
3. Use the dashboard to control the race (start, pause, reset) and trigger events (fastest lap, incident, finish).
4. All overlays update in real time via WebSocket — no manual refresh required.
